# Legal Assistant V2

Legal Assistant V2 is an AI-powered legal support application designed to help users understand legal queries, explore relevant legal information, and receive structured guidance in a simple and accessible way.

> This project is intended for educational and assistance purposes only. It does not replace professional legal advice.

## Features

- AI-based legal query assistance
- User-friendly interface for asking legal questions
- Context-aware responses for legal topics
- Support for structured legal guidance
- Backend integration with environment-based API configuration
- Clean project structure for further development

## Tech Stack

- Python
- Flask / Streamlit / FastAPI
- HTML, CSS, JavaScript
- Groq API / LLM integration
- Git and GitHub for version control
